# Citizen Connect Kenya

## Project Overview

Citizen Connect Kenya is a web-based platform designed to bridge the gap between citizens and government projects by promoting citizen participation, communication, and accountability.

The platform enables citizens to submit complaints and access government project information. Administrators can review complaints, provide feedback, and publish announcements to improve communication between citizens and relevant authorities.

## Objectives

- Promote citizen participation in government projects.
- Improve communication between citizens and administrators.
- Enable citizens to submit complaints and receive feedback.
- Share information and announcements about government activities.
- Support transparency and accountability in public service delivery.

## Key Features

### Citizen Features
- Submit complaints about community issues.
- Access government project information.
- Track complaint status.
- Receive feedback and announcements.

### Administrator Features
- Review and manage citizen complaints.
- Provide feedback on complaints.
- Manage government project information.
- Publish announcements.
- Manage users and departments.
- Generate reports on platform activities.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Database Management:** phpMyAdmin

## Installation and Setup

### Prerequisites
- XAMPP
- A web browser
- Git
- The project source code
- A clean database schema or prepared SQL file

### 1. Clone the Repository

```bash
git clone https://github.com/sasa1234Q/citizen-connect-kenya.git
```

### 2. Place the Project in XAMPP

Place the project folder inside:

`C:\xampp\htdocs\`

### 3. Start XAMPP

Start Apache and MySQL using the XAMPP Control Panel.

### 4. Configure the Database

- Open `http://localhost/phpmyadmin/`.
- Create the database required by the application.
- Import the prepared database schema.
- Configure the PHP database connection settings.

### 5. Run the Application

Open:

`http://localhost/citizen_connect_kenya/`

Adjust the database configuration and URL if your local setup differs.
